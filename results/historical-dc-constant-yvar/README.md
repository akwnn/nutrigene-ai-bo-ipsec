# Historical DC outputs (constant reconstructed variance)

These are Joseph's original DC outputs, retained byte-for-byte for auditability.
The DoE certification path used a constant reconstructed `Yvar` (derived from the
mean absolute response) instead of the per-well evaluator variance.  They are
historical evidence only and must not be used for confirmatory inference.

No numerical value in these files was edited.  Git history shows that the
adjudicator was committed after partial results already existed.  Corrected DC2
results must use the frozen variance-corrected protocol and fresh seeds 32--63.
