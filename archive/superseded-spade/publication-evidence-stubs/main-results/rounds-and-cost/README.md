# Rounds and cost

All headline comparisons use 48 wells but not necessarily the same number of rounds. SPADE
uses five rounds for C1–C3; qLogNEI uses ten rounds for C1 and five for C3; classical DoE uses
three rounds in C2; one-shot LHS uses one round in C4. The paper must report both wells and
rounds and must not translate rounds directly into unmeasured calendar or monetary savings.
