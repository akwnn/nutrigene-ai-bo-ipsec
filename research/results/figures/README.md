# Active SPADE figures

Every research figure is discoverable here. Status is expressed by subdirectory rather than
by hiding the files elsewhere:

- `terminal-rule-publication/` — complete four-figure package for the earlier terminal-rule
  manuscript, including vector/raster exports, captions, alt text, and build manifest.
- `final-spade-development/` — eight generated figures from the earlier final-SPADE study.
- `exploratory/` — diagnostic, cost-curve, scoring, and critical-difference figures from
  off-paper experiments.

The consolidated manuscript currently reports its validated results in text and tables. The
folders above make all existing artwork visible without relabelling historical figures as
evidence for the current manuscript.
