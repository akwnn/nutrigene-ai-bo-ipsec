# Active benchmark and evidence matrix

This matrix is derived from the active runners, analysers, and current canonical inputs. It
does not use archived narrative as authority. Synthetic programs share six normalized factors,
`sigma_rel=0.25`, 48 wells, a 20,000-point truth grid, a 2,000-point scoring subset, 4,096 joint
posterior draws, and reported assurance `alpha=0.95` unless a row says otherwise. “Complete”
means that the expected active grid is present; the split JSON arrays do not themselves carry a
manifest, code hash, or completion flag.

## Interpretation of “guarded”

`.venv/bin/python software/scripts/verify_conclusions.py` currently checks 12 selected scalar
values spanning C1, C3, C4, C5, and C6. It is not an exhaustive claim validator. C2 and S1 have
active standalone analysers but no assertions in that guard. S2, S3, and L1 currently lack a
complete active structured result-and-guard path; the reproduction map labels those gaps rather
than treating executable prose or archived evidence as equivalent to a canonical guarded result.
